# 0.4.0 - plan

## Goal

Three draft items about the level -> commits mapping and the page layout:

1. **Two sliders instead of amount + low/high numbers.** The amount slider (draw
   level) and the low/high number inputs steered the same thing from two sides.
   Replace all three with two commit sliders: `low / erase` and `high / draw`.
2. **Panels in workflow order:** fetch -> tools -> text -> plot -> plot info ->
   commit plan -> share.
3. **After fetch, recommend low/high from the user's real average** so the
   numbers are realistic (typically `low 5, high 10`); today's suggestion then
   reads `high` for a drawn cell, `low` for an empty one, and something in
   between for antialiased cells.

## Mapping model

- The grid still stores relative levels `0..max` (GTM1 format unchanged; the
  picture is the shape, the mapping is personal).
- `low` = commits on **erased / background** cells (level 0).
  `high` = commits on **drawn** cells (level max).
  Intermediate levels (smooth text) interpolate with the shared normalization
  `t(L) = (L+1)/(max+1)`, `t(0) = 0`, so colors and commit numbers still come from
  one formula:
  `commitsForLevel(L, max, low, high) = round(low + (high - low) * t(L))`.
- `low = 0` keeps the old meaning "background days need no commits".
- Draw paints the current top level (`max || 1`); erase paints 0. Hand-drawn
  pictures are two-tone; shades come from smooth text only. Fill uses the draw
  level; keyboard `1-9/0` goes away.
- Sliders are `0..50` commits, cross-clamped: pushing low above high drags high
  up, pulling high below low drags low down. `high >= low` always.
- `low|high` persist in localStorage (`gtm-map-v1`) next to the grid; they are
  not part of the export string.

## Recommendation after fetch

- `meanDailyCommits(map, todayMs, 90)` — mean over the 90 days before today,
  absent dates count as 0, today excluded (still in progress).
- `recommendMapping(avg)` -> `{ low: round(avg), high: max(2*low, low + 5) }`.
  Twice the usual rate separates drawn days from the day-to-day noise of
  background days; the `+5` floor keeps the picture visible for quiet accounts.
- Applied through `setMapping()` on every successful fetch (including the 6 h
  cache) and announced in the status line:
  `synced @u · 120 days with commits · graphql · avg 4.6/day (90 d) → low 5, high 10`.

## Layout (top to bottom)

1. `fetch` — username, optional PAT, fetch button.
2. `tools` — draw / erase / rect, `low / erase` slider, `high / draw` slider,
   fill / clear / undo, display mode.
3. `text` — input, font, replace, render.
4. plot — canvas + offset track (unchanged).
5. `info` — offset readout, date range, legend, today / yesterday suggestion.
6. `plan` — commit plan panel (unchanged).
7. `share` — export, PNG, import, paste.
8. footer — status line.

Every row starts with a small muted step label so the order reads as a workflow.

## Text changes

- Legend: `L0 background ≈ 5 commits` (or `(none)` when low is 0).
- Suggestion: `level 0 → ~5 commits (background)`; `no commits needed today` only
  when the number really is 0.
- Plan chips already print `L0 · 5 commits`; `rest` stays reserved for target 0.
