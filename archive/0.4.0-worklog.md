# 0.4.0 worklog — two commit sliders, workflow layout, recommended mapping

## What was built

Three draft items:

### 1. `low / erase` and `high / draw` sliders replace amount + low/high numbers

- The amount slider (which relative level to paint) and the low/high number inputs
  (what a level means in commits) were the same knob from two sides. Both are gone;
  the tools row now has two range sliders `0..50`:
  `low / erase` = commits on background (level 0) days,
  `high / draw` = commits on drawn (level max) days.
- `commitsForLevel(0, …)` now returns `low` (was hard-coded 0). `low = 0` keeps the
  old "background days need nothing" behaviour. Smooth text levels interpolate
  between the two on the same `t(L)` the colors use.
- Draw / rect / fill / pixel text paint `drawLevel() = max || 1`; erase paints 0.
  Keyboard `1-9/0` removed (D/E/R/F/C/Ctrl+Z stay).
- `setMapping(lo, hi, from)` is the single mutator: clamps, cross-clamps (the slider
  being moved wins, the other follows so `high >= low`), writes both inputs and
  readouts, refreshes colors/legend/suggestion/plan, persists to `gtm-map-v1`.
- Legend: `L0 background ≈ 5 commits` / `(none)`; suggestion:
  `level 0 → ~5 commits (background)`.

### 2. Panels in workflow order

`1 fetch` (user, PAT, fetch) → `2 tools` (draw/erase/rect, sliders, fill/clear/undo,
display) → `3 text` → plot + offset track → `4 info` (offset, range, legend, today /
yesterday) → `5 plan` → `6 share` (export, PNG, import, paste) → status footer.
Each row starts with a `.step` label; export/import moved from the header into the
share row; the legend moved from the footer into info.

### 3. Recommended low / high after fetch

- `meanDailyCommits(map, todayMs, 90)` — mean over the 90 days before today (today
  excluded, absent dates 0), walking with `setDate`.
- `recommendMapping(avg, out)` → `low = round(avg)`, `high = max(2·low, low + 5)`,
  both capped at `MAP_MAX = 50`.
- Applied via `setMapping(…, 'fetch')` on every successful fetch, cache hits
  included; status reads
  `synced @u · 90 days with commits · graphql · avg 3.9/day (90 d) → low 4, high 9`.

## Notes / decisions

- Level 0 = `low` changes the plan totals for anyone with `low > 0`: background
  days become "due" days. That is the point of the draft item — the real average
  goes on the background, drawn days go above it.
- `recommendMapping` is applied on cache hits as well; a fetch is the user's
  explicit "take my numbers" action, so it should always win over the sliders.
- The picture keeps rendering level 0 as the grey empty cell even when `low > 0`.
  The plot is a drawing surface; the legend states the background number.
- `gtm-map-v1` is separate from the grid save and not part of the GTM1 export
  string: the mapping is personal, the picture is shareable.
- Hand-drawn pictures are two-tone by design now; shades come from smooth text.
  Fill uses the draw level, so "fill then erase a shape" still works.
