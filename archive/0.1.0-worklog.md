# 0.1.0 worklog — github timeplot message

## What was built

Single-page no-build app: `index.html` (markup + inline CSS), `core.js` (pure logic),
`app.js` (DOM/canvas/events). Paint a 53x7 GitHub-style grid; each cell's level maps
to commit counts on real dates; the app suggests how many commits to make today.

Features: draw/erase/rect tools, amount slider 1..10, fill/clear, 20-step undo,
pixel text 5x7 / 3x5 / smooth antialiased (offscreen 4x downsample), offset slider
-52..+52 weeks with month/day labels, today outline, future dimming, hover tooltip
(date, level, ~commits, actual), gradient / github-quantized display, auto-save
(300ms debounce) + GTM1 import/export (string, JSON, plain numbers), GitHub sync
(graphql w/ PAT -> deno api -> public events approx), amber overlay dots for real
commits, suggestion box (today planned level -> commits, yesterday planned vs
actual), legend with commit counts, keyboard shortcuts.

## Steps

1. Rewrote `0.1.0-plan.md`: resolved open questions (t(L)=(L+1)/(max+1) from the
   draft example; 53 weeks ending Saturday with `start = end - 370d`; provider
   chain for contributions; `GTM1|off|base64` format with derived max; 3-file
   layout so node can test `core.js`).
2. `core.js` + `experiments/core-test.js` (node assertions). First run found a real
   bug: grid start computed as `end - 52*7d` -> landed on Saturday, not Sunday.
   Fixed to `end - (W*H-1)*DAY`; also fixed quantized palette mapping to be
   rank-based so level 1 is never "empty" and level max is always darkest.
3. `index.html` + `app.js` per plan (phases 2..7 in one pass).
4. `experiments/dom-smoke.js`: minimal DOM shim that imports the real `app.js` and
   drives init, hover, a paint stroke, text render, offset changes, paste import,
   export, clear + undo. First run failures were all bad test expectations
   (wrong expected end date; "today outside grid" only happens for negative
   offsets; reading localStorage before the autosave debounce) — app behavior was
   correct; tests fixed.
5. Served over `python3 -m http.server` for the live preview; verified 200s.
6. Docs: findings, README, archived plan.
