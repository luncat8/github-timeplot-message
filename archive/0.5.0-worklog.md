# 0.5.0 worklog — demo button, centered today, track direction, robust recommendation, smooth font

## What was built

Five draft items (the sixth, "links to users who used this tool", is deferred):

### 1. demo button (simulated plot)

- `fetch` row gains `demo`: one click sets offset +26, fills the grid with a light
  typical-account background (level-1-only sparse noise, weekday-weighted
  (`base 16`, weekends `6`), slow busy-season waves via `sin(c * 0.55)`), merges a
  centered smooth `hello world` over it and applies the typical recommended
  mapping `low 5 / high 10`.
- Seeded LCG (`seed = seed * 1664525 + 1013904223`) — the picture (README
  screenshot) is reproducible pixel-for-pixel.
- Writes its state into the visible controls (text input, font select) so the
  screen shows how it was made; `pushUndo()` first, so undo reverts it.
- `smoothText(text, replace)` gained an explicit `replace` argument: the text row
  passes the checkbox, the demo passes `false` (merge — noise survives between
  the glyphs).

### 2. README header screenshot

- `experiments/header-shot.js`: serves the repo over localhost (ES modules do not
  load from `file://`), clicks `demo`, screenshots `#plotWrap` at 2x into
  `header.png`; embedded at the top of the README.
- Browser resolution: plain `playwright`, or `SHOT_MODULES=<node_modules>` for
  `playwright-core` + `@sparticuz/chromium` (binary bundled in the npm package —
  the playwright browser CDN is blocked here). The bundled libs only extract when
  the package believes it is on an AWS Lambda node runtime —
  `AWS_EXECUTION_ENV=AWS_Lambda_nodejs22.x` outside Lambda.

### 3. today centered

- Fresh sessions start at `offset = 26` (today at column `52 - 26 = 26`, the
  center of 53): half a year of history left, half a year of plan right. Saved
  sessions keep their stored offset (`loadSaved`), demo forces 26.

### 4. track follows the plot

- `offsetToX` / `xToOffset` mirrored: the thumb now moves the same direction as
  the plot's dates — dragging right shifts the grid right. End labels swapped
  (`+52w` left = future, `-52w` right = past); today marker stays mid-track.
- Track keys are spatial now (Home = left end = +52, End = -52, ArrowRight = older);
  the plot/track wheel convention (scroll down = into the past) is unchanged.

### 5. robust low / high after fetch

- `recommendMapping(map, todayMs, out)` replaces the 90-day mean with nearest-rank
  quantiles of the 90 daily counts (today excluded, absent = 0, insertion-sorted
  in a module scratch `Int32Array`): `low = med`, `high = max(p90, 2*low, low + 5)`,
  capped at `MAP_MAX`. Spikes and inactive stretches no longer drag the numbers.
- `out.med` / `out.p90` reported in the status line:
  `… · med 4, p90 4 (90 d) → low 4, high 9`. `meanDailyCommits` removed.

### 6. smooth font quality

- Real bug found: the `getImageData` sampler's y term missed the `* 4` byte
  stride (`(y0 + py) * gw + x0 * 4`), reading a vertically squashed strip of the
  glyph bitmap — every row sampled the wrong pixels. Fixed to
  `((y0 + py) * gw + x0) * 4 + 3`.
- Fit + center on the measured ink bounding box
  (`actualBoundingBoxAscent/Descent`) instead of the em-box middle with a
  hard-coded 0.72 cap-height guess; draw with `textBaseline = 'alphabetic'` at
  `y = (gh + asc - desc) / 2`. Fill raised to 0.96 w / 0.94 h.
- Contrast stretch on the per-cell coverage: `< 0.16` → background, `> 0.62` →
  solid top level (`max(1, …)` keeps edge cells). Glyph strokes get a crisp
  top-level core instead of a washed-out mid-level blur; edges stay antialiased.
  "hello world" over light noise reads cleanly at 7 rows.
